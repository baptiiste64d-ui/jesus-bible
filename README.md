# Jésus-Christ — Histoire et Bible

Site français, pensé pour le téléphone, offert par **Baptiste** à **Luigi Jimenez**.

Il présente l’histoire de Jésus-Christ, permet de lire la **Bible Louis Segond 1910** (domaine public), et propose des cantiques en fond sonore (sans lecture automatique).

## Adresse

Lorsque le site est publié sur GitHub Pages :

https://baptiiste64d-ui.github.io/jesus-bible/

## Contenu

- **Accueil** — introduction respectueuse, avec une animation-cadeau à la première visite.
- **Son histoire** — texte original (naissance, baptême, ministère, miracles, enseignements, Passion, crucifixion, résurrection, ascension), avec renvois vers le lecteur biblique.
- **La Bible** — Louis Segond 1910, liste des livres, navigation par chapitre, taille du texte, thème clair/sombre, mémorisation de la position, recherche.
- **À propos** — sources et licences.

## Sources

Voir la page [À propos](apropos.html) pour le détail des licences.
